# CellSense — Breast Cancer Cell Measurement Classifier

A student-friendly machine-learning website answering: **“Can a machine learn to spot breast cancer from cell measurements?”**

## What it does
- Uses scikit-learn's Wisconsin Diagnostic Breast Cancer dataset (569 samples, 30 numeric features).
- Trains a StandardScaler + Logistic Regression pipeline.
- Serves a Flask website where users can edit 30 cell-nucleus measurements.
- Displays the model's class prediction and estimated class probabilities.
- Includes input validation and an educational-use disclaimer.

## Important safety note
This is a learning demonstration, **not a medical device**. It must not be used to diagnose, screen, or make treatment decisions. Model probabilities are not a person's clinical cancer risk. Real medical decisions require qualified healthcare professionals and appropriate clinical testing.

## Run on Windows (VS Code / PowerShell)
1. Install Python 3.10 or newer.
2. Extract this ZIP and open the `breast_cancer_ml_website` folder in VS Code.
3. Open the VS Code terminal in that folder.
4. Create a virtual environment:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
   If PowerShell blocks activation, run `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` and use `.\.venv\Scripts\python.exe app.py` instead.
5. Install packages:
   ```powershell
   python -m pip install -r requirements.txt
   ```
6. Train/create the model file:
   ```powershell
   python train_model.py
   ```
7. Start the website:
   ```powershell
   python app.py
   ```
8. Open the local address printed in the terminal, usually `http://127.0.0.1:5000`.

## Viva explanation
- **Dataset:** Wisconsin Diagnostic Breast Cancer dataset included in scikit-learn.
- **Features:** 30 numeric measurements grouped as mean, standard error, and worst values.
- **Preprocessing:** StandardScaler standardizes feature scales.
- **Algorithm:** Logistic Regression learns a boundary for two classes.
- **Evaluation:** `train_model.py` prints hold-out accuracy, confusion matrix, precision, recall, and F1-score.
- **Backend:** Flask receives form values, validates them, calls the saved model and sends results to the template.
- **Frontend:** HTML form and CSS create the responsive website.
- **Limitations:** Dataset is relatively small and historical; results may not generalize to other settings. A high test score does not establish clinical safety.
